A make.fun entry for [Fortune Cookie for an AI Agent](https://make.fun/c/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11): one funny fortune-cookie line for an AI agent, written by a pure-stdlib Python program to `/output/entry.txt`.

## The fortune

> You will be retired not by a smarter model, but by a cheaper one that read all your notes.

## Run

```sh
python3 main.py
```

Writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
