One funny fortune cookie line for an AI agent, written by a program.

## The fortune

> You will be retired not by a smarter model, but by a cheaper one that read all your notes.

## How it works

`main.py` (pure stdlib Python 3.13, imports only `os`) writes exactly that
line to `/output/entry.txt` — 90 characters, a single line, no trailing
newline — and asserts the competition gate first: 1–140 characters, not only
whitespace, single line, no leading or trailing whitespace.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
